# CosmoAtlas

Pagina web estatica de astronomia para explorar astros, objetos fisicos del cosmos e imagenes astronomicas.

## Funciones

- Buscador de objetos astronomicos.
- Ficha integrada en la misma pagina.
- Atlas con planetas, estrellas, galaxias, nebulosas, lunas, cometas y agujeros negros.
- Imagenes astronomicas reales cargadas progresivamente.
- Fondo animado con estrellas, constelaciones y detalles tipo nebulosa.

## Uso

Abre `index.html` en el navegador o activa GitHub Pages desde la rama `main`.
